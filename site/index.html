Your system's architecture, as a map you can walk through

arch-map reads a codebase and draws an interactive 3D map of it: from the people and systems that use it down to modules, endpoints, tables and contracts. The map is generated, so it stays true to the code — and the same JSON specs it is drawn from are there for an AI agent to read.

Try the demo ↓ View on GitHub

Generated from code

Stack adapters read the code (read-only) and write specs. NestJS backends and Supabase projects — Postgres with RLS, Edge Functions, React clients — ship with it; a new stack is a module that writes the same format.

Zoom from people to tables

Start at the client layer, then wheel into a system, an application, its endpoints. Path shows a whole call chain down to the tables it touches; Scenarios play a user flow step by step.

Specs are the interface

Plain JSON with a schema, validated and merged by the checks. Hand-written overlays add what code can't say: actors, scenarios, envelopes. Embed the map anywhere with @arch-map/viewer.

your code→stack adapter→specs/*.json+overlay→checks→3D map & AI agents

Run it on your code

arch-map runs from a checkout on Node.js 22.18+, no build step. The viewer opens the example projects first; point it at a directory of your own projects to map your systems.

Adding a project · Adding a stack · Embedding the map

To show a map in a page of your own, install the viewer from npm: @arch-map/viewer — mount(), an <arch-map> element, a React wrapper or a single script.

git clone https://github.com/tkabanov/arch-map
cd arch-map && npm ci
npm run viewer            # http://localhost:4848

# generate a project's specs from its code
npm run gen -- <project>

# embed the map in your own page
npm install @arch-map/viewer
